# Арцах — приватный концепт
ID кандидата: C-006.
Статический сайт без зависимостей, готовый production-каталог dist.
Из папки проекта: `node validate.mjs`; `python3 -m http.server 4316 --directory dist`.
BRIEF.md — источники и ограничения, QA.md — проверка. Оригинальная художественная иллюстрация, не фотография блюда. До официального запуска согласовать факты и материалы с владельцем.

## Доработка 11.09.2026
Демо доступно всем по ссылке по прямому запросу Ильгиза. Предыдущие записи о приватности описывают первую версию. Встроена карта Яндекса, добавлена локальная подготовка обращения. Автоматической отправки и хранения данных нет: посетитель сам открывает проверенный канал. Подробности и ограничения BRIEF.md. Чужие фото и цены не выдуманы.
